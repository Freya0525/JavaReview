final关键字
1.final的使用
1.1final修饰类
表示这个类不能被继承，没有子类。提高安全性，提高程序的可读性。
例如：String 类，System类，StringBuffer类
final class Eunuch{
}

class Son extends Eunuch{} //错误，final类不能被继承

1.2final修饰方法
表示这个方法不能被子类重写。
例如：Object类中的getClass()

1.3final修饰变量
final int age =17;
final修饰的变量只能赋值一次，不能重新赋值。

注意重点！！！！：
final成员变量 ✅ 可以先声明，后在构造器中赋值
final局部变量 ❌ 必须在使用前完成赋值
