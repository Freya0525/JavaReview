可变个数的形参
当定义一个方法时，形参的类型可以确定，但是形参的个数不确定，那么可以考虑使用可变个数的形参。

格式：
方法名(参数的类型名 ...参数名)

举例：
public static void test(int a ,String ...books)
String    ...     books
  ↓        ↓        ↓
数据类型  可变参数   参数名

也就是说，调用 test() 方法时，books 可以接收 0 个、1 个或多个字符串。
可以这样调用：
test(1);                          // 0本书
test(1, "Java");                  // 1本书
test(1, "Java", "Python");        // 2本书
test(1, "Java", "Python", "C++"); // 3本书

特点：
1.可变参数：方法参数部分指定类型的参数个数是可变多个：0个，1个或多个
