面向对象特征之一：封装性（encapsulation）
java如何实现数据封装
- 实现封装就是控制类或成员的可见性范围。这就是需要依赖访问控制修饰符，也称为权限修饰符来控制。
- 权限修饰符：public、protected、缺省、private。


属性私有化
* 封装的体现：
 * 成员变量/属性私有化
 * 概述：私有化类的成员，提供公共的get和set方法，对外暴露获取和修改属性的功能。
 * 实现步骤：
 * 使用private 修饰成员变量
 * private 数据类型 变量名;

 比如：
private int age;
相当于把 age 锁起来
外部 ──────X──────> age
       不能直接访问

但是提供两个门：
              setAge()
外部 ──────────────────> 修改 age

              getAge()
外部 <────────────────── 获取 age

也就是：
             ┌─────────────────┐
             │     Person      │
             │                 │
setAge() ───>│  private age    │
getAge() <───│                 │
             └─────────────────┘
为什么不直接把属性设成 public？
public int age;
p.age = 20;
但无法有效控制别人怎么修改它。
直接公开public int age;
别人可以：
p.age = 20;
p.age = -1000;
p.age = 999999;

使用 private + setter
private int age;

public void setAge(int age) {
    if (age >= 0 && age <= 150) {
        this.age = age;
    }
}
现在所有人想修改 age，都必须经过：setAge()
你就可以在这个“入口”进行检查。
这就是“封装”

私有化类的成员变量，提供公共的 get 和 set 方法，对外暴露获取和修改属性的功能。
大白话：把属性藏起来，不允许外部直接随便操作；如果外部想读取或修改，就必须通过我提供的方法来操作。

private 属性  → 不让外部直接访问
setXxx()      → 给外部提供“修改”的入口
getXxx()      → 给外部提供“读取”的出口
